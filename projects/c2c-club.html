C2C Club

Website for the Campus to Career Club at AUIS — events, RSVP, success stories, Arabic/English toggle, and a Firestore-backed CMS that lets non-technical admins manage all content.

The Challenge

Club websites typically die after the original developer graduates — admins can't update content without modifying HTML. The objective was to build a system where non-technical club officers could manage event listings, success stories, and site copy through a secure admin panel, with no code required.

What Was Built

Firestore-backed CMS

All dynamic content — event cards, success story entries, hero text — is stored in Firestore and loaded at runtime. Admins edit content through a secure dashboard protected by Firebase Authentication. Changes are live immediately with no deploy step.

Event RSVP system

Members can RSVP to events directly on the site. Responses are stored in Firestore and visible to admins in the dashboard with attendee counts and names.

Arabic/English toggle

A single-click language toggle switches the entire UI between Arabic (RTL) and English, serving both the local student body and international visitors without duplicate pages.
