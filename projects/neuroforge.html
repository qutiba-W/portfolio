NeuroForge

Brain training PWA with six games and offline support — runs in the browser with no install required.

The Concept

Cognitive training should be accessible without an app store and usable offline. NeuroForge is a Progressive Web App — no install, no account required — that treats the browser as the training environment. Six distinct games target different cognitive domains: working memory, attention, peripheral vision, arithmetic under pressure, pattern reversal, and rapid visual search.

Architecture

PWA with offline-first service worker

A service worker caches all game assets on first load. The app runs fully offline after that — no network dependency mid-session. Progress is persisted in localStorage and survives cache updates.

Web Audio API for cognitive feedback

Sound cues are generated programmatically via the Web Audio API — no audio file downloads. This keeps the app lightweight and ensures timing accuracy for reaction-based games where audio latency matters.

Six game modes

Dual N-Back, Chaos Schulte, Split-Brain Protocol, Serial Sevens, Reverse Replay, and Peripheral Vision. Each targets a different cognitive subsystem. Difficulty adapts based on session performance.
