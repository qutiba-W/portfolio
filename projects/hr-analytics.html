HR Analytics — Retention Prediction

Random Forest classification model on HR data — 95% accuracy predicting employee attrition, with feature importance analysis revealing the top churn drivers.

The Question

Employee turnover is expensive but often treated as unpredictable. This project asked: can a machine learning model identify which employees are at risk of leaving — and more importantly, can feature importance analysis tell us why, so leadership can address root causes rather than symptoms?

The Analysis

Exploratory Data Analysis

EDA with Pandas and Matplotlib on a large HR dataset — distributions, correlations, and class imbalance analysis before touching any model. Identified that the dataset required stratified sampling to avoid training a model that just predicted "stays."

Model comparison

Compared Logistic Regression against Random Forest. Logistic Regression reached ~82% on the test set; Random Forest reached >95% with default hyperparameters, confirmed with cross-validation to rule out overfitting.

Feature importance — what actually drives attrition

The model's top predictors were "lack of recent performance evaluation" and "chronic overwork hours" — not salary. The actionable recommendation was a restructured review cycle, not a compensation increase.
